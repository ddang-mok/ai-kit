# 범용 데이터 점검 / 1차 EDA

## 입력
README에서 확인한 목적/KPI 후보, 제공 데이터 경로. 데이터가 없으면 `미제공`을 보고하고 가짜 분석을 하지 않는다.

## 절차
1. 파일·시트·테이블 목록, 확장자, 용량, 인코딩, 행·열 수를 파악한다. 큰 데이터는 청크/표본으로 분석하고 분석 범위를 표시한다.
2. 컬럼별 이름, 타입, 가능한 의미, 단위, 키 후보, 시간 범위를 표로 만든다. 의미 불명은 미확인으로 남긴다.
3. 파일 간 관계/조인 키, 키 유일성, 참조 누락, 그레인(행이 나타내는 단위)을 확인한다.
4. 결측률, 중복, 비정상 범위, 형식 불일치, 이상치, 주요 통계/범주 빈도 등을 계산한다.
5. 숫자·범주·시간별 분포와 타깃 후보의 가용성을 확인하되 **문제별 심층 분석은 다음 스킬**에서 한다.
6. 개인정보/민감한 데이터, 타깃 누수, 대표성, 시간·집단 분할 위험을 기록한다.
7. 데이터 품질 문제가 KPI/알고리즘에 주는 영향을 `심각/주의/낮음`으로 제안한다.

## 도구
- CSV/TSV 간이 검사는 `python .agents/skills/02-dataset-audit/scripts/profile_csv.py <파일경로>`를 활용할 수 있다(표준 라이브러리만 사용, 원본 읽기 전용).
- Excel 등은 이미 설치된 라이브러리를 우선 사용하고, 설치가 필요하면 먼저 사용자에게 이유를 설명한다.

## 출력
- 파일/스키마 개요 + 데이터 관계
- 품질 이슈 표: 컬럼/증거/비율/영향/권장 처리
- 확인된 분포·기초 패턴 5개 이내
- 문제 해결에 쓸 수 있는 데이터와 누락 데이터
- 원본 변경 없이 할 수 있는 다음 심층 분석 질문

## 품질 게이트
관측 결과에 실제 `n`, 계산 대상과 범위(전체/표본), 기준, 근거가 명시된다. 상관관계를 인과관계로 주장하지 않는다.

## 금지
원본 자동 정제·삭제·덮어쓰기, 무단 외부 전송, 실제 데이터가 없는 상태에서 결과를 꾸미는 행위.
